## 1. 概要

### 1.1 一言説明（エレベーターピッチ）

マインクラフトJavaEditionのjourneymapというModを使って、自分のワールドの地図を見たい人向けに、「マインクラフト未起動時にjourneymapの地図ビューワーの閲覧および、編集ができない」という課題を、「マインクラフト未起動時でもjourneymapの地図ビューワーの閲覧および、編集ができる」ようにすることによって解決するWebアプリケーション。

> ※ MVP（v1.0）ではタイル画像による地図閲覧のみを対象とし、waypoint表示・編集機能は含みません（詳細は1.4スコープ・5.2機能一覧・12章リリース計画を参照）。このピッチ文言と実際のMVPスコープの間にギャップがあることは把握した上で、あえて許容しています（Q23、13.2 Q-3参照）。

### 1.2 背景・解決したい課題

- 現状：マインクラフト起動時及び、localhost8080を起動できている状態のみwebでの閲覧が可能。
- 課題：「マインクラフト未起動時にjourneymapの地図ビューワーの閲覧および、編集をしたい」「外出中に地図を閲覧したい、https通信経由でウェブサイトを閲覧したい」というニーズを満たせない
- 現在の代替手段とその限界：マインクラフト起動時及び、localhost8080を起動できている状態のみwebでの閲覧が可能。地図の画像を保存して、ペイントアプリでポイントやライン、ポリゴンデータの代用を手で描画している。

### 1.3 目的・ゴール

| #   | 目的                                                                                                              | 達成できたと判断する基準                                                                                                                                                                                       |
| --- | ----------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| G-1 | マインクラフト未起動・外出中でも、自分のワールドの地図（タイル画像）をスマホ/PCのブラウザから閲覧できるようにする | 自分のPCでエクスポート→Cloudflareへのデプロイが実行でき、スマホから発行したURLでOverworldの地図（昼/夜/地形レイヤー）がパン・ズーム・レイヤー切替・座標表示付きで閲覧できること（Q24：技術検証重視の成功基準） |
| G-2 | 個人開発として無理のない運用コスト・作業負荷に抑える                                                              | Cloudflare無料枠内で運用でき（13.2 Q-1で解決済み、実測168MBで無料枠に十分な余裕を確認）、更新作業（エクスポート＋デプロイ）を都度手動で実行できること（Q9, Q14, Q17）                                          |

## 3. 提供価値と成功指標

### 3.1 ユーザーにとっての価値

- マイクラ未起動時でも自分のワールドの地形を確認しながら、次の行動計画を考えられる
- 外出中でもスマホから地図（タイル画像）を確認できる

### 3.2 成功指標（KPI）

個人利用のプロダクトのため厳密なKPIは設定せず、Q24で定めた技術検証ベースのMVP成功基準を採用する。

| 指標        | 定義                        | 目標値                                                     | 計測方法                             |
| ----------- | --------------------------- | ---------------------------------------------------------- | ------------------------------------ |
| MVP成功可否 | Q24の技術検証基準の達成状況 | エクスポート→デプロイ→スマホ表示の一連の操作が成功すること | 実際に一連の操作を自分で実行して確認 |

## 5. 機能要件

### 5.1 機能構成図

```
マイクラMAPエディター
├── 地図表示（Web）
│   ├── タイル表示（pan/zoom, Leaflet）
│   ├── レイヤー切替（昼/夜/地形）
│   └── 座標表示・コピー
├── エクスポート/デプロイ（開発者操作・ローカルスクリプト）
│   ├── JourneyMapローカルデータの読み取り（.minecraft/journeymap/data）
│   ├── タイル変換・R2への全量アップロード（フルシンク、対象は day/night/topo/waypoints/biome の168MBのみ、chunk_cacheは除外）
│   └── （v1.1）waypointデータのUI表示
└── （v1.1以降）waypoint機能
    ├── 一覧表示
    ├── 検索
    └── 地図上マーカー表示・ジャンプ
```

### 5.3 機能詳細

#### F-001：タイル地図表示

| 項目               | 内容                                                                                                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 概要               | Overworldの地図タイル（昼/夜/地形）をLeaflet上でパン・ズーム表示する                                                                                        |
| 利用者             | 一般ユーザー                                                                                                                                                |
| 事前条件           | Cloudflare R2上に最新のタイルデータがアップロード済みであること（F-005）                                                                                    |
| 入力項目           | なし（閲覧のみ）                                                                                                                                            |
| 処理内容           | 推測困難なURLへのアクセスをもって、R2上の静的タイルをLeafletで読み込み表示する                                                                              |
| 出力・画面表示     | 地図タイル、レイヤー切替UI、座標表示パネル                                                                                                                  |
| 事後条件           | なし                                                                                                                                                        |
| 正常系の流れ       | 1. ユーザーがURLにアクセス<br>2. 初期レイヤー（例：昼）のタイルが表示される<br>3. パン・ズーム操作で任意のエリアを閲覧できる                                |
| 異常系・エラー処理 | ・タイルが存在しない場合：空白/デフォルト表示（明確なエラー画面までは実装しない）<br>・通信失敗の場合：ブラウザ標準の再読み込みに委ねる                     |
| 補足・確認事項     | JourneyMapのローカルタイル構造がWeb標準（XYZタイル等）とそのまま互換かは未検証（Q12、13.2 Q-2）。ディレクトリ構成自体は2026-08-06に実地確認済み（13.3参照） |

#### F-004：エクスポートスクリプト

| 項目               | 内容                                                                                                                                                                                                                                                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 概要               | `.minecraft/journeymap/data` 配下のタイルPNG・waypoint JSON・biomeデータを読み取り、Web配信用の構造に変換する                                                                                                                                                                                                                        |
| 利用者             | 管理者（自分）                                                                                                                                                                                                                                                                                                                       |
| 事前条件           | JourneyMap Modでワールドをプレイ済みで、ローカルにタイルデータが存在すること                                                                                                                                                                                                                                                         |
| 入力項目           | ワールドセーブのパス（固定でよい、Q7でシングルワールド限定のため）                                                                                                                                                                                                                                                                   |
| 処理内容           | Overworldのday/night/topo/waypoints/biome（計168MB）を対象に走査・変換する（Cave/Nether/Endは対象外、Q10・Q13）。**chunk_cache（JourneyMap内部の生チャンクキャッシュ、.jmcファイル、945MB）は、day/night/topoに既に描画済みでWeb表示に不要なため、走査・エクスポート対象から明示的に除外する**（2026-08-06実地調査で確定、13.3参照） |
| 出力・画面表示     | デプロイ用に整形されたタイルファイル一式（約168MB）                                                                                                                                                                                                                                                                                  |
| 事後条件           | F-005の入力として利用可能な状態になる                                                                                                                                                                                                                                                                                                |
| 正常系の流れ       | 1. プレイ終了後にスクリプトを手動実行<br>2. ローカルデータ（chunk_cacheを除く）を走査しタイル・waypoint・biomeを変換<br>3. 変換結果をローカルに出力                                                                                                                                                                                  |
| 異常系・エラー処理 | ・JourneyMapの内部フォーマットが変わっている場合：スクリプトが失敗する可能性あり（R3、13.1参照）<br>・waypoint JSONはエクスポート対象に含めるが、v1のフロントエンドUIでは表示しない（v1.1で表示対応、F-006）                                                                                                                         |
| 補足・確認事項     | Mod更新によるフォーマット変化リスクを意図的に許容（Q8）。エクスポート対象を絞り込んだことで、元データ1.07GBの約16%（168MB）のみを扱えばよいことが判明（13.3参照）                                                                                                                                                                    |

#### F-005：デプロイスクリプト

| 項目               | 内容                                                                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 概要               | F-004で出力したタイル・waypoint・biomeデータ（約168MB）をWrangler CLI等でCloudflare R2へ全量アップロードする                              |
| 利用者             | 管理者（自分）                                                                                                                            |
| 事前条件           | F-004の出力が存在すること、Cloudflareの認証情報が設定済みであること                                                                       |
| 入力項目           | なし（固定のR2バケットに対して実行）                                                                                                      |
| 処理内容           | 差分検出は行わず、毎回全ファイル（約780ファイル）を上書きアップロードする（フルシンク、Q11）                                              |
| 出力・画面表示     | なし（CLIの実行結果ログのみ）                                                                                                             |
| 事後条件           | R2上のタイルが最新化され、F-001から閲覧可能になる                                                                                         |
| 正常系の流れ       | 1. F-004完了後にスクリプトを実行<br>2. 全ファイル（約168MB、約780ファイル）をR2へアップロード<br>3. 完了後、Web上の地図が最新化される     |
| 異常系・エラー処理 | ・アップロード中に失敗した場合：新旧タイルが混在した中途半端な状態が一時的に公開される可能性がある（R6、意図的に許容）                    |
| 補足・確認事項     | CI/CDは使用せず、ローカル実行のみ（Q19）。月30回同期してもClass A操作は約23,400回で無料枠（100万回/月）に対し十分な余裕がある（13.3参照） |

## 7. データ要件

### 7.1 主要エンティティ

実際の`journeymap_export`ディレクトリ（合計1.07GB）の実地調査結果（2026-08-06）に基づく。詳細は13.3参照。

| エンティティ             | 説明                                                                                              | 主な属性                               | 実測サイズ・ファイル数 | エクスポート対象                               |
| ------------------------ | ------------------------------------------------------------------------------------------------- | -------------------------------------- | ---------------------- | ---------------------------------------------- |
| タイル画像（day）        | Overworld昼レイヤータイル                                                                         | ズームレベル, X座標, Y座標, PNG画像    | 78MB / 260ファイル     | 対象                                           |
| タイル画像（night）      | Overworld夜レイヤータイル                                                                         | 同上                                   | 61MB / 260ファイル     | 対象                                           |
| タイル画像（topo）       | Overworld地形レイヤータイル                                                                       | 同上                                   | 22MB / 260ファイル     | 対象                                           |
| biomeデータ              | JourneyMap内部のバイオーム関連データ（地図描画補助用と推定）                                      | 未詳細（用途は実装時に確認、13.2 Q-4） | 8.2MB                  | 対象                                           |
| waypoint（v1.1でUI表示） | JourneyMap上のwaypoint                                                                            | 名前, 座標, アイコン, 色               | 4KB / 1ファイル        | 対象（エクスポートはv1から実施、UI表示はv1.1） |
| chunk_cache（対象外）    | JourneyMap内部の生チャンクキャッシュ（.jmcファイル）。day/night/topoに既に描画済みでWeb表示に不要 | -                                      | 945MB / 246ファイル    | **対象外**（エクスポート・アップロードしない） |

**エクスポート/アップロード対象合計：約168MB**（day+night+topo+biome+waypoints、元データ1.07GBの約16%）

### 7.2 エンティティ関連

RDBは使用せず、タイル画像・JSONを静的ファイルとしてCloudflare R2に格納するため、ER図は省略する。

### 7.3 データの取り扱い

| 項目             | 内容                                                                                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 保持期間         | 明確な期限なし（個人利用のため）                                                                                                                             |
| 削除方針         | 物理削除は基本行わない（フルシンクで同一パスを上書き、Q11）。無料枠超過時（Q17）にデータ範囲縮小を選ぶ場合は手動削除を検討                                   |
| バックアップ     | ローカルPC(エクスポート元)が実質的な原本。R2側の別途バックアップは無し（MVPスコープ外）                                                                      |
| 個人情報の有無   | 無（マインクラフトのワールドデータのみ、個人情報は含まない）                                                                                                 |
| 容量試算（参考） | 実測168MB（2026-08-06時点、chunk_cache除外後）。R2無料枠10GBに対し余裕が大きく、現状の探索量の約60倍に達するまで枠内に収まる見込み（13.2 Q-1解決、13.3参照） |

### 13.3 解決済み事項の記録

#### Q-1：Cloudflare R2無料枠試算（2026-08-06解決）

実際の`journeymap_export`ディレクトリ（合計1.07GB）を調査した結果:

| ディレクトリ          | 内容                                         | サイズ | ファイル数 | エクスポート対象                             |
| --------------------- | -------------------------------------------- | ------ | ---------- | -------------------------------------------- |
| overworld/day         | 昼レイヤータイル                             | 78MB   | 260        | 対象                                         |
| overworld/night       | 夜レイヤータイル                             | 61MB   | 260        | 対象                                         |
| overworld/topo        | 地形レイヤータイル                           | 22MB   | 260        | 対象                                         |
| overworld/biome       | バイオームデータ                             | 8.2MB  | -          | 対象                                         |
| waypoints             | waypoint JSON                                | 4KB    | 1          | 対象（v1.1でUI表示予定）                     |
| overworld/chunk_cache | JourneyMap内部の生チャンクキャッシュ（.jmc） | 945MB  | 246        | **対象外**（day/night/topoに描画済みで不要） |

**結論**：R2へのエクスポート・アップロード対象は day/night/topo/waypoints/biome の計168MBのみ（元データ1.07GBの約16%）。chunk_cacheはJourneyMapが再描画用に使う内部キャッシュであり、Web地図表示（day/night/topoに既に描画済み）には不要なため、エクスポート/アップロード対象から除外する。

**無料枠試算**：
- ストレージ：168MB ≪ 10GB（無料枠）。現状の探索量の約60倍に達するまで枠内に収まる
- Class A操作（PUT）：1回のフルシンクで約780ファイル。月30回同期しても23,400回 ≪ 100万回/月（無料枠）

この結果を受け、R-4（無料枠圧迫リスク）は「中/中」から「低/低」に格下げした（13.1参照）。あわせて、chunk_cacheをエクスポート対象から除外する方針をF-004（エクスポートスクリプト）・7.1（データ要件）・1.4（スコープ）に反映した。
