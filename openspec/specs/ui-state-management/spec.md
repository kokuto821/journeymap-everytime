# ui-state-management Specification

## Purpose
グローバルなUI状態(テーマ選択を皮切りに、今後のレイヤー選択・座標表示等)をProvider肥大化やバケツリレーを避けて共有するための状態管理基盤を提供する。
## Requirements
### Requirement: テーマ選択状態の共有
システムはUIツリー内の任意のコンポーネントから現在選択中のテーマ名を参照でき、テーマ名を変更する手段を提供しなければならない(SHALL)。

#### Scenario: 初期表示時のテーマ
- **WHEN** アプリケーションを起動する
- **THEN** 既定のテーマ名がルート要素の`data-theme`属性に反映される

#### Scenario: テーマ切替時の即時反映
- **WHEN** コンポーネントがテーマ名の変更を要求する
- **THEN** ルート要素の`data-theme`属性が新しいテーマ名に更新され、UI全体に反映される

### Requirement: 状態管理基盤の拡張性
システムは今後追加されるグローバルUI状態(レイヤー選択・座標表示等)を、新たなReact Context Providerを追加することなく同じ仕組みで管理できなければならない(SHALL)。

#### Scenario: 新規状態の追加
- **WHEN** 開発者がテーマ選択以外の新しいグローバルUI状態を追加する
- **THEN** 既定の状態管理方針(store配置ディレクトリ・命名規則)に従うだけで、既存のProviderツリーに変更を加えずに追加できる
