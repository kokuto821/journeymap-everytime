## Purpose

エクスポート済みの地図データをCloudflare R2へアップロードし、Web地図ビューから最新の探索状況を閲覧できる状態にする。

## ADDED Requirements

### Requirement: R2へのフルシンクアップロード
システムは、エクスポート済みの全データファイルをCloudflare R2へ、差分検出を行わずに全量上書きアップロード(フルシンク)しなければならない(SHALL)。

#### Scenario: デプロイスクリプトを実行する
- **WHEN** 管理者がエクスポート完了後にデプロイスクリプトを実行する
- **THEN** エクスポート済みの全ファイルがCloudflare R2の所定バケットへ上書きアップロードされる

#### Scenario: アップロード完了後に最新化される
- **WHEN** デプロイスクリプトが正常に完了する
- **THEN** 地図ビューでR2上の最新タイルが閲覧可能になる

#### Scenario: アップロード中に失敗する
- **WHEN** アップロード処理の途中で通信エラー等により失敗する
- **THEN** R2上には新旧のファイルが混在した状態が一時的に残る可能性があることを許容する
